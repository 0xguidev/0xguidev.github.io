# Introdução ao React

React é uma biblioteca JavaScript para construir interfaces de usuário. Criada pelo Facebook, ela permite criar componentes reutilizáveis e gerenciar o estado da aplicação de forma eficiente.

## Por que React?

- **Componentes Reutilizáveis**: Crie pedaços de UI que podem ser reutilizados em diferentes partes da aplicação.
- **Virtual DOM**: Otimiza as atualizações do DOM real, melhorando a performance.
- **Comunidade Ativa**: Grande ecossistema de bibliotecas e ferramentas.

## Conceitos Básicos

### JSX

JSX é uma extensão de sintaxe para JavaScript que permite escrever HTML dentro do código JavaScript.

```jsx
const element = <h1>Olá, mundo!</h1>;
```

### Componentes

Componentes são funções que retornam elementos React.

```jsx
function Welcome(props) {
  return <h1>Olá, {props.name}</h1>;
}
```
